# Puerto Pacífico Sur — sitio web

Sitio del proyecto Puerto Pacífico Sur / Lomas de Jesús, Punta de Bombón, Islay, Arequipa, Perú.

## Estructura

- `index.html` — portada
- `astillero.html` — Astillero y Varadero
- `puerto-multiproposito.html` — Puerto Multipropósito (calado 20 m)
- `cruceros.html` — Cruceros y Aeropuerto
- `terrenos.html` — Terrenos Casa Playa y Parque Logístico
- `nautico.html` — Club Náutico Lomas de Jesús
- `legal.html` — situación legal y documentos
- `contacto.html` — contacto
- `img/` — fotografías aéreas reales del predio (también embebidas en base64 dentro de cada página)
- `diseno/` — referencias de trabajo (opciones de paleta, sistema visual) — no forman parte del sitio publicado

## Publicar con GitHub Pages

1. Settings → Pages → Deploy from a branch → `main` / `/ (root)`
2. El sitio queda en `https://<usuario>.github.io/puerto-pacifico-sur-peru/`
3. Para dominio propio, agregar un archivo `CNAME` con el dominio y configurar el DNS del proveedor.

## Paleta

- Home / Legal / Contacto: Carta Náutica (navy/rojo/arena)
- Astillero / Puerto Multipropósito / Cruceros: Acero y Cobre
- Terrenos / Club Náutico: Pacífico Claro (teal/turquesa)

Las cifras técnicas y financieras corresponden a estudios en curso y están sujetas a ingeniería de detalle.
